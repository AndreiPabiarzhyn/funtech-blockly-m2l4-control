# Rabbit Run — Blockly

Мини-игра для обучения программированию с помощью Blockly. Игрок управляет кроликом, собирает морковки и проходит уровни, составляя программы из блоков или управляя кроликом с клавиатуры.

Автор: Andrei Pabiarzhyn · для Kodland

## Что это
Короткая интерактивная обучающая игра (web) — уровни с режимом "program" (выполнение последовательности команд) и "keyboard" (управление с помощью обработчиков клавиш и событий столкновений). Подойдёт для уроков по блоковому программированию (Blockly).

### Стек
- **Язык(и):** JavaScript, CSS, HTML
- **Рантайм / фреймворк:** Браузерный JavaScript, Blockly (v10) для визуального редактора
- **Основные библиотеки:** Blockly (подключается через CDN или/и поставлен в libs/)
